# SillyTavern 小游戏中心

一个纯前端、零后端依赖的 SillyTavern 第三方扩展。

目前内置：
- 💣 扫雷
- 🔢 2048
- 📦 推箱子

## 安装

### 方式 1：Git 安装
把这个文件夹上传到 GitHub，然后在 SillyTavern：
扩展 → Install Extension → 输入 GitHub 仓库 URL。

### 方式 2：手动安装
把整个 `st-game-center` 文件夹放进 SillyTavern 的第三方扩展目录。

当前版本的 SillyTavern 文档推荐第三方扩展使用 `data/<用户>/extensions`，全用户共享扩展也可以使用 `public/scripts/extensions/third-party`。

## 使用
酒馆页面右下角会出现一个 🎮 按钮，点击即可打开小游戏中心。
