# Silly Game

**当前版本：v1.8.1**

SillyTavern 里的纯前端小游戏集合。

## 游戏
扫雷、2048、推箱子、数独、蜘蛛纸牌、五子棋、数字华容道、俄罗斯方块、围棋、倒水瓶、小农场、叠蛋糕、消灭星星、连连看、数方、国际象棋、中国象棋、UNO。

## v1.7.3
- 清理重复 CSS 规则与重复属性，保留最终级联结果。
- 新增 UNO：108 张牌、你 + 3 名本地 AI；支持数字、跳过、反转、+2、变色、+4、摸牌、喊 UNO。
- UNO 胜利解锁农场作物“苹果”。
- JS / manifest / README 版本号统一为 1.6.6。

## 更新检查
每次进入/刷新 SillyTavern 时后台检查一次 GitHub 托管版本。通过 GitHub 安装的扩展可使用更新流程。


## v1.7.3
- 新增 UNO 专属牌面与桌面视觉：彩色圆角卡牌、椭圆牌芯、可出牌高亮、牌堆与变色选择器。


## v1.7.3
- UNO 明确区分“摸牌堆”和“出牌区”。
- AI 回合间隔提高到约 1.3 秒，方便看清每次 AI 出的牌。
- 当前出牌增加短暂落牌动画与动作提示。
- 万能牌选色提示不再以大块遮罩盖住整个中心区域。


## v1.7.3 UNO
- 严格区分同色、同数字/同功能牌。
- +4 按经典规则仅在手中没有当前颜色牌时可出。
- 摸牌后只能处理这张新牌；不能出则可“过牌”。
- 颜色选择器移动到 AI 2 下方的空白区域，不遮挡牌桌。
- 不可出的手牌自动弱化并禁用点击。


## v1.7.3
- 新增三消：交换相邻软糖方块、连锁消除、30步目标挑战。
- 三消通关解锁农场作物「桃花」。
