# Silly Game

一个纯前端、零后端依赖的 SillyTavern 小游戏扩展。

目前内置：
- 💣 扫雷：7 档难度、首次点击保护、长按标记、数字点击展开、局面自动保存、局部放大与方向微调
- 🔢 2048：方向键、触摸滑动、方向按钮、自动保存
- 📦 推箱子：11 个关卡、方向按钮、键盘控制
- 🔲 数独：9×9、3 档难度、错误提示、数字键盘
- 🕷️ 蜘蛛纸牌：1 / 2 / 4 花色、撤销、提示
- ⚫ 五子棋：15×15、本地 AI / 双人模式、无需 API
- 💧 倒水瓶：60 个关卡 + 无尽模式：颜色分类、多关卡、撤销、自动保存

## 安装

将包含 `manifest.json` 的整个文件夹安装到 SillyTavern 第三方扩展目录，或在扩展安装器中输入 GitHub 仓库地址。

## SillyTavern 扩展设置

安装后，SillyTavern 的「扩展」设置页会出现 **Silly Game** 折叠项，可直接控制悬浮按钮是否显示。设置会使用 SillyTavern 的扩展设置持久化。

## API

五子棋当前使用前端本地 AI，不需要配置 API。以后如果想增加“调用你当前模型来下棋”的模式，可以再额外做成可选功能。


## 自动更新
Silly Game 会优先通过 SillyTavern 的扩展发现接口定位实际安装目录，并使用实际目录名调用版本检查与 Git 更新接口。这样 GitHub 仓库名与扩展文件夹名不一致时也能正常识别。
