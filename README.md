## 更新检查
每次进入/刷新 SillyTavern 时，插件会在后台检查一次 GitHub 托管版本。只有发现新版本时才弹出提示，并在「检查更新」按钮上显示红点；不会在后台擅自更新。

## 安装
推荐通过 SillyTavern 的第三方扩展 GitHub 安装方式安装，以便版本检查能够识别 Git 仓库。
