# Silly Game

**当前版本：v1.9.2**

SillyTavern 里的纯前端小游戏集合。

## v1.9.1｜角色陪玩增强
- 角色陪玩由“单角色”升级为“最多 3 名角色同时陪玩”，对应 UNO 三个 AI 席位。
- 角色选择改为多选；未选满的席位自动由本地 AI 补位。
- 新增“AI 生成预设”选择，可读取酒馆当前 API 类型下已经保存的 API 预设。
- 选择指定 API 预设时，陪玩生成会临时套用该预设，生成结束后自动恢复酒馆原先使用的预设，不长期改动用户当前设置。
- 当前角色仍优先使用 quiet generation，以保留当前角色与聊天上下文；其他已选角色继续按角色卡内容生成。
- UNO 的每个角色席位都会使用自己的角色身份、手牌与行动回合。

## v1.9.0｜角色陪玩
- 新增「角色陪玩」核心入口，角色玩家层与具体游戏解耦，后续斗地主、五子棋、象棋、围棋可复用。
- 首发接入 UNO：酒馆角色拥有真实手牌并参与回合。
- 当前角色优先使用 SillyTavern 的后台 quiet generation，保留角色与当前聊天上下文；从角色列表选择的其他卡使用角色卡文本进行原始生成。
- 角色只负责选择行动和简短台词，合法性、摸牌、出牌、胜负全部由 Silly Game UNO 引擎裁定。
- 角色返回非法行动时自动回退到本地 AI，不会卡死牌局。
- 首页新增「角色陪玩」入口；可选择当前角色/角色列表角色，并开关角色台词。
- UNO 角色陪玩与原有本地 AI 模式兼容，关闭窗口时仍会保存当前牌局。

## v1.9.2｜角色陪玩预设与兼容性修复
- 角色陪玩 API 预设改为读取 SillyTavern 全部“聊天补全预设”，不再跟随当前 RP 所使用的预设。
- 陪玩默认独立选择预设；RP 可以使用高阶模型，小游戏可以单独选择更轻量、更便宜的预设。
- 修复预设临时切换时给 `selectPreset()` 传入预设名称的问题，改为使用正确的 preset option value，并在生成后恢复原预设。
- UNO 角色生成改为显式 `generateRaw({ prompt })`，不再强依赖 `response_format/json_schema`，提高 OpenAI 兼容中转端的兼容性；非法 JSON/动作会重试一次，仍失败则回退本地 AI。
- 内置角色陪玩提示词增强：游戏引擎负责裁判，模型只从当前允许行动中选择。
