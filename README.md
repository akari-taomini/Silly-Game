# Silly Game · SillyTavern 小游戏扩展

一个纯前端、零后端依赖的 SillyTavern 第三方扩展。

## 当前游戏
- 💣 扫雷（新手 / 初级 / 中级 / 高级 / 专家 / 大师 / 地狱 7 档难度）
- 🔢 2048（方向键 / 手机方向键 / 滑动 + 自动保存）
- 📦 推箱子（11 个关卡 + 方向键）
- 🔲 数独

## 这一版的改动
- UI 改为尽量跟随 SillyTavern 当前主题，不再固定黑色/紫色弹窗。
- 使用 SillyTavern 常见主题变量，如 `--SmartThemeBodyColor`、`--SmartThemeBlurTintColor`、`--SmartThemeBorderColor` 等。
- 扫雷保留清爽的白色棋盘格。
- 扫雷支持右键标记，以及“已翻开的数字 + 周围旗子数量正确 → 再次点击自动展开”。
- “重新开始”现在是原地重置游戏状态，不会重新复制一套 UI，也不会叠加事件监听。
- 2048、推箱子也使用原地重置。
- 游戏切换时会清理键盘事件监听。

## 安装
将本文件夹作为扩展安装，目录内第一层应直接包含：

```text
manifest.json
index.js
style.css
README.md
```

也可以将仓库 URL 直接用于 SillyTavern 的第三方扩展安装功能。

### 数独
标准 9×9 数独，支持简单 / 中等 / 困难三档。题目随机生成，并在出题时校验唯一解；支持鼠标、手机数字键盘和电脑 1–9 / Delete / 方向键操作。


### 0.6.0
- 插件正式命名为 `Silly Game`。
- 浮动入口改为真正可拖动的悬浮按钮，电脑与手机均支持拖动。
- 悬浮按钮位置会保存到浏览器本地，窗口尺寸变化时会自动限制在屏幕内。
- 增加悬浮按钮设置，可隐藏；隐藏后收成屏幕边缘的小把手，手机也可以一键恢复。
- 电脑端支持 `Alt + G` 恢复隐藏按钮或直接打开 Silly Game。

### 0.5.0
- 扫雷增加大师 / 地狱两档，共 7 档难度。
- 2048 增加实体方向键，电脑可点击方向键避免误触；手机同样可直接点击。
- 2048 使用本地存档，刷新酒馆页面后可以恢复当前棋盘。
- 推箱子增加到 11 个关卡，并加入关卡选择与下一关按钮。
- 2048 / 推箱子的方向键监听采用捕获阶段，减少与 SillyTavern 页面快捷键或滚动行为冲突。


## 悬浮按钮
- 右下角默认显示 Silly Game 悬浮按钮。
- 电脑和手机都可以直接拖动到任意位置，位置会自动保存。
- 设置中可以隐藏悬浮按钮；隐藏后会缩成屏幕边缘的小把手，点击即可恢复。
- 电脑端也支持 `Alt + G` 恢复 / 打开。
